# 0.3.0 重构规格（唯一事实来源）

> 状态：**已拍板**，实现以本文为准。任何与本文冲突的旧实现、旧文档、旧注释一律作废。
> 版本：0.3.0（`VERSION` 已切）。安全锚点：tag `pre-rewrite-0.2.10`、分支 `archive/0.2.10`。

---

## 0. 一句话

**把"同一条事实有多条实现路径"从根上删掉**：受控端到服务端只有**一条链路**、**一条命令路径**、**一处在线判定**、**一份时钟**；旧协议收进一个显式隔离的兼容层，0.4 删除。

## 1. 硬约束（违反即返工）

| # | 约束 | 判定方式 |
|---|---|---|
| C1 | 设备入网/心跳/命令/回执/事件**只有一条逻辑链路**：WebSocket 与 HTTP 长轮询只是同一条链路的两个**载体**，语义完全一致，切换载体不改变任何行为 | 代码里搜不到第二套 heartbeat/result 实现 |
| C2 | 帧上传**只有一条**：`POST /api/v1/agent/frames`（原始字节），与链路载体无关 | 无 WS 二进制帧分支（旧兼容层除外） |
| C3 | 命令**只有一个创建点**、**只有一个回执点**；等待方用 `async with` 作用域，退出即清理 | 无全局 waiter 字典无界增长 |
| C4 | presence/capabilities **只有一个函数**产出；任何地方要判断在线都必须调它 | `registry` 不允许被 UI/业务直接读 |
| C5 | 时间**只有一个来源**：服务端时钟。所有带时间的响应含 `server_time_ms`；需要预算的含 `deadline_ms`。设备上报的时间字段一律命名 `device_time_ms` | 前端无 `Date.now()` 参与新鲜度判断 |
| C6 | 破坏性动作（删除/归档/更新/卸载）**成功或可观测失败**，禁止 fire-and-forget 静默 | 每条路径有状态与重试/告警 |
| C7 | 旧协议兼容代码**只允许存在于 `server/observatory/legacy/`**，不许被新代码 import | `grep -r "from .*legacy" server/observatory` 仅 main/装配处 |
| C8 | 配置项**要么生效要么不存在**：`Settings` / `settings_store` 里每个键必须有消费者 | 有测试断言 `SPECS` 每键被读取 |

## 5. 协议 v3

### 5.1 信封

```json
{ "v": 3, "id": "<uuid4>", "t": "<type>", "ts_ms": 1730000000000, "body": { ... } }
```

- `t` 下行：`welcome | config | command | control | ping | pong | uninstall | update_offer`
- `t` 上行：`hello | heartbeat | result | event | control_frame | uninstall_ack | pong`
- 未知 `t` 必须忽略并可观测（不崩、不断链）。
- 二进制帧（仅 WS 载体的控制画面）：`uint32 BE 头长 | JSON 头 | payload`，头含 `t:"ctrl"`、`session`。

### 5.2 端点（新增）

| 端点 | 用途 |
|---|---|
| `POST /api/v1/agent/link` | 上行批次 → 返回下行批次（可 hold ≤20s）；同时刷新存活 |
| `WS /api/v1/agent/link` | 同上，实时双向 |
| `POST /api/v1/agent/frames` | 帧上传（原始字节，`X-Frame-Id` 幂等键） |

### 5.3 幂等与重投

- 上行 `id` 在服务端去重（5 分钟 LRU）→ 重投安全。
- 下行 `command.id` 在受控端去重，重复执行返回同一回执。
- 帧 `X-Frame-Id` 在服务端去重 → 重传不产生重复帧。
- HTTP 载体：服务端 hold 20s，客户端超时 30s；断线重连后用 `last_ack_id` 续传（outbox 重投未确认消息）。

### 5.4 超时预算（一次写死，不许各接口自定）

```
服务端 deadline = min(命令类型上限, 25s)   # 命令类型上限见下
客户端超时     = deadline + 5s
命令类型上限：files 25s · update 60s · uninstall 60s · sysinfo 60s · 其余 20s
```
响应体带 `deadline_ms`（相对毫秒），客户端据此设置超时；前端不再使用固定 20s。

### 5.5 错误码

`AUTH | GONE | BAD_REQUEST | UNSUPPORTED | TIMEOUT | RATE | INTERNAL`，全部 `{code, message, retryable}`。
HTTP 状态码映射：AUTH→401/403、GONE→410、BAD_REQUEST→422、UNSUPPORTED→422、TIMEOUT→504、RATE→429。

### 5.6 线上格式（权威，服务端与受控端逐字段一致）

**HTTP 载体** `POST /api/v1/agent/link`

```json
// 请求
{"v":3, "last_ack_id":"<上次收到的最后一条下行 id，可空>", "items":[<上行信封>...]}
// 响应
{"v":3, "ack_id":"<本批处理完成的上行信封 id；无上行则回显请求的 last_ack_id>", "server_time_ms":1730000000000, "items":[<下行信封>...]}
```
无下行时服务端 hold ≤ 20s 再返回空 items；客户端超时 30s。

**WS 载体** `WS /api/v1/agent/link`
- 首条上行：`hello`，body = `{agent_version, protocol:3, boot_id, device_uid, last_ack_id, device_time_ms}`
- 首条下行：`welcome`，body = `{server_version, heartbeat_interval_s, server_time_ms, config?, update_offer?}`

**信封 body 形状**

| t | 方向 | body |
|---|---|---|
| `config` | ↓ | `{"config": {...}, "server_time_ms": int}` |
| `command` | ↓ | `{"command_id", "type", "payload", "deadline_ms"}` |
| `control` | ↓ | `{"session", "action": "start"\|"input"\|"stop", "fps"?, "quality"?, "deadline_ms"?, "ev"?}`（输入事件就是 `action="input"` + `ev`，不再单独开类型） |
| `ping` | ↓ | `{"server_time_ms": int}` |
| `heartbeat` | ↑ | `{"agent_version", "boot_id", "device_time_ms", "state": {...}, "sysinfo": {...}?}` |
| `result` | ↑ | `{"command_id", "ok", "result"?, "error"?, "error_code"?, "elapsed_ms", "device_time_ms"}` |
| `event` | ↑ | `{"event", "data"}` |
| `control_frame` | ↑ | 二进制（WS 载体）：`u32 头长 | {"t":"ctrl","session":...} | 字节` |
| `uninstall_ack` | ↑ | `{"ok", "error"?}` |
| `pong` | ↑ | `{"device_time_ms"}` |

**帧上传** `POST /api/v1/agent/frames?device_ts_ms=<int>&session_id=<int>&kind=screen|camera`
- 头：`X-Device-Token`、`X-Frame-Id: <uuid>`、`Content-Type: image/jpeg`
- 响应：`{"frame_id", "ts_ms", "stored": true, "server_time_ms"}`
- `X-Frame-Id` 重复 → 返回同一 `ts_ms`，不重复入库、不重复转码。

**未知 `t`**：接收方记 warning 后丢弃（不得断链、不得崩）。

| `settings` | key PK, value JSON, updated_at_ms | 不变 |
| `packages` | id, kind, version(idx), filename, size_bytes, sha256, notes, created_at_ms, UNIQUE(kind, version) | 不变 |
| `frame_archives` | id, device_id, frame_id, day TEXT, remote_path, sha256, size_bytes, status(待上传/已上传/失败/已删除), attempts, created_at_ms, uploaded_at_ms, error | 归档状态机 |
| `install_tokens` | id, token_hash(uniq), created_by, created_at_ms, expires_at_ms, used_at_ms, used_device_id, max_uses INTEGER DEFAULT 1 | 一次性安装令牌 A18 |

**迁移列表**（`core/db.py` 有序函数，必须幂等）：

- `v1`：0.2.10 基线（6 张表）。老库检测方式：`devices` 存在但 `schema_version` 不存在 → 直接 stamp 为 1。
- `v2`（0.3.0）：
  - `ALTER devices ADD boot_id`, `ADD protocol`
  - `ALTER frames ADD device_ts_ms`, `ADD frame_id`, `ADD archived_at_ms`；`CREATE UNIQUE INDEX ux_frames_device_frame ON frames(device_id, frame_id)`
  - `ALTER commands ADD error_code`, `ADD attempts`, `ADD deadline_ms`
  - `CREATE TABLE frame_archives`, `CREATE TABLE install_tokens`
- 迁移前置：sqlite backup API 备份到 `data/backups/pre-migrate-v<N>-<ts>.db`；失败则**不启动**并打印恢复命令。
- 回滚：迁移失败自动还原备份文件后退出非 0。

| 风险 | 控制 |

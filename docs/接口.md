# 接口

基础前缀 `/api/v1`。除标注 `公开` 的接口外，控制台接口需要会话（`Authorization: Bearer <token>`
或登录时下发的 HttpOnly Cookie `obs_session`）；受控端接口需要 `X-Device-Token`。

所有返回时间都是 epoch 毫秒（整数）。**任何描述设备状态的响应都带 `server_time_ms`**，
前端必须用它而不是本机时钟来判断新鲜度。

## 0.3.0 变化摘要

* 设备链路升级为**协议 v3 信封**（`{v,id,t,ts_ms,body}`），新增 `POST/WS /api/v1/agent/link`；
  WebSocket 与 HTTP 长轮询是同一链路的两个载体，语义一致。
* 旧端点（`/agent/enroll`、`/agent/heartbeat`、`/agent/commands`、`WS /agent/ws` 等）继续可用，
  由服务端兼容层翻译；0.2.x 受控端可零重装升级。
* 安装凭据改为**一次性安装令牌**（`?token=`）；旧 `?code=` 共享注册码仅用于兼容。
* 错误体统一为 `{code,message,retryable}`；JSON 示例里的版本号统一为 0.3.0。
* 需要等待的接口返回 `deadline_ms`，客户端按 `deadline_ms + 5s` 设置超时（不再固定 20s）。

## 状态模型

`presence` 对象是设备状态的唯一来源：

```json
{
  "state": "online | degraded | offline | uninstalling | uninstalled",
  "transport": "ws | poll | none",
  "reason": "实时通道已连接",
  "last_seen_ms": 1760000000000,
  "age_ms": 1200,
  "channel_since_ms": 1759999900000,
  "capabilities": {
    "control": true, "files": true, "screenshot": true,
    "timeline": true, "update": true, "uninstall": true
  }
}
```

| state | 含义 | transport | control | files/screenshot |
| --- | --- | --- | --- | --- |
| `online` | WebSocket 通道活跃 | `ws` | ✅ | ✅ |
| `degraded` | 只有轮询通道，或刚掉线但仍在窗口内 | `poll`/`none` | ❌ | ✅ |
| `offline` | 超过 120 秒无任何上报 | `none` | ❌ | ❌ |
| `uninstalling` | 已下发卸载，等待受控端确认 | 任意 | ❌ | ❌ |
| `uninstalled` | 受控端已确认卸载 | `none` | ❌ | ❌ |

判据：WebSocket 通道 65 秒无流量、轮询通道 150 秒无刷新才丢弃，避免"来回跳动"。

## 认证

### POST `/auth/login` — 公开
```json
{"password": "…", "totp": "123456"}
```
`200`：`{"token":"…","expires_at_ms":…,"version":"0.3.0"}`，并 `Set-Cookie: obs_session=…; HttpOnly; SameSite=Strict`。
`401`：密码错误；或 `{"detail":"需要二次验证码"}` / `"验证码错误"`。
`429`：同一 IP 5 分钟内超过 8 次。

### POST `/auth/logout`
清除 Cookie，写审计。

### GET `/auth/session` — 公开（用于引导）
```json
{"authenticated": true, "totp_enabled": false, "version": "0.3.0",
 "server_time_ms": 0, "console_host": "control.tianhw.top", "base_urls": ["…"]}
```

### POST `/auth/totp/setup`
返回 `{"secret":"…","uri":"otpauth://…"}`。**尚未启用**，需要下一步校验。

### POST `/auth/totp/enable`
```json
{"secret": "…", "code": "123456"}
```
校验通过才写入。

### POST `/auth/totp/disable`
```json
{"code": "123456"}
```
**必须**带验证码并校验通过。缺 body → `422`；码错 → `400`。
（0.1 版本这里不校验，任何有效会话都能关掉二次验证——已修复。）

### POST `/auth/password`
```json
{"current_password": "…", "new_password": "至少 10 位"}
```

## 设备

### GET `/devices`
```json
{"devices": [Device…], "server_time_ms": 0, "server_version": "0.3.0"}
```

`Device`：
```json
{
  "uid": "OBS-1A2B3C4D5E6F", "name": "车间-01", "hostname": "PC-01",
  "os_name": "Windows", "os_version": "11 23H2", "arch": "AMD64",
  "agent_version": "0.3.0", "enrolled_at_ms": 0, "last_seen_ms": 0, "note": "",
  "presence": {…}, "sysinfo": {…}, "settings": {…},
  "latest_frame_id": 42, "server_time_ms": 0
}
```

`settings` 是该设备的**生效配置**（服务器默认值 + 设备覆盖）。

### GET `/devices/{uid}`
`{"device": Device, "server_time_ms": 0}`

### PATCH `/devices/{uid}`
```json
{"name": "新名字", "note": "备注", "settings": {"capture_interval_s": 60}}
```
`settings` 只接受可按设备覆盖的键（见 `/settings` 的 `specs[*].per_device`）；其他键返回 `400`。
修改会立即推送给在线受控端。

### DELETE `/devices/{uid}`
`?purge_remote=true|false`（默认 true，同时删除归档仓库中的该设备文件）。
设备仍在线时返回 `409`：先远程卸载，避免留下"还在上报但已不存在"的机器。

### POST `/devices/{uid}/uninstall`
```json
{"confirm": true}
```
`confirm` 是**必填**字段（0.1 的前端漏发 body，导致远程卸载永远 422）。
`200`：`{"command_id":"…","status":"dispatched","message":"…不会弹 UAC"}`
`409`：设备不在线 / 已卸载。

### POST `/devices/{uid}/commands`
```json
{"type": "screenshot", "payload": {}, "confirm": false}
```
允许的 `type`：`screenshot` `collect_now` `sysinfo` `files` `log_tail` `update`
`reload_config` `restart_agent` `uninstall` `reboot` `poweroff`。
`uninstall`/`restart_agent`/`reboot`/`poweroff` 必须 `confirm: true`。

返回 `Command`：
```json
{"id":"…","type":"screenshot","status":"pending|dispatched|ok|error|timeout|cancelled",
 "payload":{},"result":{},"error":null,
 "created_at_ms":0,"dispatched_at_ms":0,"finished_at_ms":0}
```

### GET `/devices/{uid}/commands?limit=50`
### GET `/devices/{uid}/commands/{command_id}`

## 画面

### GET `/devices/{uid}/frames/latest`
`{"frame": {"id":42,"ts_ms":0,"width":1600,"height":900,"size_bytes":12345,"has_thumb":true,"kind":"screen"}, "server_time_ms":0}`

### GET `/devices/{uid}/frames/{frame_id}?variant=thumb|full`
返回图像字节。响应头：`Cache-Control: public, max-age=31536000, immutable`、`ETag`。
画面不可变，**URL 不要加时间戳参数**——0.1 的做法让每次拖动时间线都重新下载。

### GET `/devices/{uid}/timeline?from_ms&to_ms&bucket_ms`
```json
{"from_ms":0,"to_ms":86400000,"bucket_ms":60000,
 "buckets":[{"ts_ms":0,"frame_id":42,"frame_count":3,"session":1}],
 "total_frames": 128, "server_time_ms": 0}
```
服务端按时间桶聚合，最多 900 个桶；跨度上限 31 天（超出 `400`）。

### GET `/devices/{uid}/frames?from_ms&to_ms&limit`
逐帧列表（导出/调试用）。

### DELETE `/devices/{uid}/frames`
清空该设备历史画面（含文件）。

## 文件

### GET `/devices/{uid}/files?path=`
`path` 为空 → 列出驱动器；否则列出目录。
```json
{"path":"C:\\Users","parent":"C:\\","truncated":false,
 "entries":[{"name":"a.txt","path":"C:\\Users\\a.txt","is_dir":false,"size":12,
             "mtime_ms":0,"hidden":false,"drive":"C:"}],
 "drives":[{"name":"系统 (C:)","path":"C:\\","is_dir":true,"size":0,
            "free":123,"filesystem":"NTFS"}],
 "server_time_ms":0}
```
设备不可操作时 `409`，`detail` 是具体原因（例如"仅轮询通道…"）。

### POST `/devices/{uid}/files/op`
```json
{"op":"mkdir|delete|rename|copy|move|search|stat|hash|drives|list",
 "path":"C:\\x","target":"新名字","recursive":false,"pattern":"*.txt"}
```
读写成对返回：`{"ok":true,"op":"list","data":{},"error":null,"elapsed_ms":12}`。
`read`/`write` 请用下面的分片接口。写操作会写审计。

### GET `/devices/{uid}/files/raw?path&offset&length`
分片读取（`length` ≤ 1 MiB）。响应体是原始字节，响应头：
`X-File-Size` `X-Chunk-Offset` `X-Chunk-Length` `X-Eof`。

### PUT `/devices/{uid}/files/raw?path&offset&truncate`
请求体是分片字节（≤ 1 MiB）。`offset=0&truncate=true` 表示新建/覆盖。
返回同 `files/op`。浏览器按 1 MiB 顺序上传即可支持任意大小文件。

## 实时控制

### POST `/devices/{uid}/control`
```json
{"confirm": true, "ttl_s": 300}
```
`200`：`{"token":"…","expires_at_ms":0,"fps":8,"quality":55,"ws_path":"/api/v1/devices/{uid}/control"}`
`409`：设备不是 `online`（需要 WebSocket），`detail` 说明原因。
`403`：该设备禁用了实时控制。

### WS `/devices/{uid}/control?token=<grant>`
* 服务端 → 浏览器：`{"type":"ready","fps":8,"quality":55,"expires_at_ms":0}`，随后是二进制 WebP 帧
* 浏览器 → 服务端（JSON）：
```json
{"type":"input","ev":{"kind":"mouse","action":"move|down|up","x":5000,"y":5000,"norm":true,"button":1}}
{"type":"input","ev":{"kind":"wheel","delta":-1}}
{"type":"input","ev":{"kind":"key","code":65,"down":true}}
{"type":"input","ev":{"kind":"text","text":"你好"}}
```
坐标 `norm: true` 时是 `0..10000` 归一化值，由受控端换算成屏幕像素。
关闭码：`4401` 授权无效，`4409` 无实时通道。

### DELETE `/devices/{uid}/control/{token}`
主动结束会话。

## 安装令牌（A18）

安装不再使用长期共享注册码。控制台（管理员会话）签发**一次性安装令牌**：

### POST `/install-tokens`
生成令牌（写审计 `install.token_create`），请求体：
```json
{"ttl_s": 1800}
```
`ttl_s` 可省略（默认 1800 = 30 分钟），允许范围 60..86400 秒。响应（`stamp` 会补 `server_time_ms`）：
```json
{"id": 7, "token": "…", "expires_at_ms": 1760000000000, "max_uses": 1,
 "install_cmd_url": "/api/v1/public/install.cmd?token=…",
 "install_ps1_url": "/api/v1/public/install.ps1?token=…&download=1"}
```
令牌明文只在此响应中出现一次；服务端只存 `token_hash`。

### GET `/install-tokens`
列出令牌（不含明文）：
`{"tokens":[{"id":7,"created_by":"…","created_at_ms":0,"expires_at_ms":0,"used_at_ms":0,"used_device_id":null,"max_uses":1}]}`。

### DELETE `/install-tokens/{token_id}`
撤销（写审计 `install.token_delete`）。已过期/已使用的令牌不可复用；撤销立即生效。

### 安装脚本下载（公开）
`GET /public/install.ps1?token=…`、`GET /public/install.cmd?token=…`
（`?download=1` 仍表示附件）。令牌无效/过期/已使用 → `401`（`code=AUTH`）。
旧 `?code=<共享注册码>` 仅用于 0.2.x 兼容并继续可用（不内联进新生成的安装包）。

### 消费语义
* 首次 `POST /agent/enroll` 携带 `install_token` → 原子地标记已使用并绑定该 `uid`；
* 令牌默认 TTL 30 分钟（`OBS_INSTALL_TOKEN_TTL_MINUTES`，0=禁用签发）；
* 同一令牌不能用于第二台设备；重装需要新令牌；
* 旧设备/旧服务端可继续使用 `OBS_ENROLL_CODE`，行为不变。

## 受控端接口（两个域名都提供）

### 协议 v3（0.3.0 新链路）

信封（WS 与 HTTP 长轮询共用，二者只是载体）：

```json
{ "v": 3, "id": "<uuid4>", "t": "<type>", "ts_ms": 1730000000000, "body": { } }
```

| 端点 | 用途 |
| --- | --- |
| `POST /api/v1/agent/link` | 上行批次 → 返回下行批次（可 hold ≤20s）；同时刷新存活 |
| `WS /api/v1/agent/link` | 实时双向 |
| `POST /api/v1/agent/frames` | 帧上传（原始字节，`X-Frame-Id` 幂等键） |

- 上行 `id` 在服务端去重（5 分钟 LRU）；下行 `command.id` 在受控端去重。
- HTTP 载体：服务端 hold 20s，客户端超时 30s；断线重连用 `last_ack_id` 续传。
- 需等待的响应带 `deadline_ms`（相对毫秒）；服务端 deadline = min(类型上限, 25s)，
  类型上限：files 25s · update/uninstall 60s · sysinfo 60s · 其余 20s。

以下旧端点保留给 0.2.x（兼容层翻译到新核心）。

### POST `/agent/enroll` — 公开，凭一次性安装令牌或旧注册码
```json
{"install_token":"…","uid":"OBS-…","hostname":"PC-01","os_name":"Windows",
 "os_version":"11 23H2","arch":"AMD64","agent_version":"0.3.0",
 "sysinfo":{}, "sessions":[]}
```
（旧客户端可把 `install_token` 换成 `code`：共享注册码，仅 0.2.x 兼容。）
`200`：
```json
{"device_uid":"…","token":"…","config":{…},
 "base_urls":["https://control.tianhw.top","https://observatory.123423.xyz"],
 "server_version":"0.3.0","server_time_ms":0,"heartbeat_interval_s":20}
```
同一 `uid` 重复注册会**轮换令牌**（重装后仍保持设备身份）。
`401` 安装令牌/注册码无效、已过期或已被使用，`403` 服务器未开启注册，`429` 频率限制。

### POST `/agent/heartbeat`（`X-Device-Token`）
```json
{"agent_version":"0.3.0","sysinfo":{"cpu_percent":5.2},"state":{"transport":"ws","spool":0}}
```
`200`：
```json
{"config":{…},"server_time_ms":0,"heartbeat_interval_s":20,"poll_hold_s":25,
 "update":{"version":"0.3.0","url":"/api/v1/public/agent/0.3.0/package",
           "sha256":"…","size_bytes":0} | null,
 "uninstall": false, "commands":[Command…]}
```

### GET `/agent/commands?wait=20`（长轮询）
有命令立即返回；否则最多挂起 `wait` 秒（服务端上限 25 秒），命令一到立刻唤醒。
返回 `{"commands":[…],"server_time_ms":0,"config":{…},"update":…}`。

### POST `/agent/commands/{id}/result`
```json
{"ok": true, "result": {}, "error": null}
```

### POST `/agent/frames?ts_ms&session_id&kind`（`X-Device-Token`）
请求体是图像字节（WebP/PNG/JPEG 均可，服务端统一转 WebP + 缩略图）。
返回 `{"frame_id":42,"ts_ms":0,"stored":true,"server_time_ms":0}`。

### POST `/agent/uninstall/ack`
受控端删除自己前调用，服务端标记 `uninstalled_at_ms`。

### GET `/agent/state`
设备自查：返回它自己的 `presence`、服务器版本、下发的地址列表与配置。

### WS `/agent/ws`（`X-Device-Token`）
服务端 → 设备：
```json
{"t":"welcome","device_uid":"…","server_version":"0.3.0","server_time_ms":0,
 "heartbeat_interval_s":20,"config":{…},"update":null,"poll_hold_s":25}
{"t":"config","config":{…}}
{"t":"command","command":{"id":"…","type":"files","payload":{…},"timeout_ms":90000}}
{"t":"ctrl_start","session":"<grant>","fps":8,"quality":55,"ttl_s":600}
{"t":"ctrl_in","session":"<grant>","ev":{…}}
{"t":"ctrl_stop","session":"<grant>"}
{"t":"ping","ts":0}
```
设备 → 服务端：
```json
{"t":"hello","agent_version":"0.3.0","sysinfo":{}}
{"t":"heartbeat","agent_version":"0.3.0","sysinfo":{},"state":{}}
{"t":"result","command_id":"…","ok":true,"result":{},"error":null}
{"t":"event","event":"update_started","data":{}}
{"t":"uninstall_ack"}
{"t":"pong"}
```
二进制消息使用：`uint32 头长度 | JSON 头 | 负载`。
`{"t":"frame"}` 是采集画面，`{"t":"ctrl"}` 是控制画面（按 `session` 转发给浏览器）。
关闭码：`4401` 令牌无效，`4002` 设备已卸载。

```json
    "base_urls": ["https://control.tianhw.top", "https://observatory.123423.xyz"],

      {"kind": "cmd", "label": "安装程序 (.cmd)", "filename": "Observatory-Install-0.3.0.cmd", "url": "/api/v1/public/install.cmd?token=<一次性令牌>", "hint": "在「安装令牌」页生成一次性令牌后下载，双击运行"},

```

## 控制台 WebSocket

### WS `/ws?token=<会话令牌>`
服务端推送：
```json
{"type":"hello","ts_ms":0,"device_uid":"","data":{"version":"0.3.0","server_time_ms":0,"heartbeat_s":20,"channels":{"ws":0,"poll":0}}}
{"type":"tick","ts_ms":0,"device_uid":"","data":{"server_time_ms":0,"channels":{…},"clients":1}}
{"type":"device_updated","ts_ms":0,"device_uid":"OBS-…","data":{}}
{"type":"device_removed" | "command_created" | "command_updated" |
 "frame_added" | "uninstall_progress" | "notice" | "version", …}
```
关掉这个 socket 时前端必须把状态显示为"状态未知"而不是沿用旧值。

## 错误格式

0.3.0 统一为结构化错误体：

```json
{"code": "AUTH", "message": "注册码/令牌无效", "retryable": false}
```

| `code` | HTTP | 含义 | retryable |
| --- | --- | --- | --- |
| `AUTH` | 401/403 | 未登录、令牌失效、注册码错误、能力被禁用 | 否（换凭据后重试） |
| `GONE` | 410 | 设备已卸载/资源已不存在 | 否 |
| `BAD_REQUEST` | 400/422 | 参数、设置、文件名不合法 | 否 |
| `UNSUPPORTED` | 422 | 能力不支持/命令类型未知 | 否 |
| `TIMEOUT` | 504 | 超过服务端 deadline | 是 |
| `RATE` | 429 | 频率限制 | 是（退避） |
| `INTERNAL` | 500/502 | 服务端/受控端内部失败 | 视情况 |

兼容层（旧端点）仍可能返回 `{"detail": "中文说明"}`；0.2.x 客户端不需要改。
常见状态码语义：`404` 不存在或访问了受控端域名的控制台路径；`409` 状态冲突
（设备在线不能删除、非 online 不能开实时控制）；`413` 图像/分片过大；`422` 请求体缺字段。

# 发布与更新链路（0.3.7 末起：GHCR 拉取式交付，无本地构建）

> 最终形态（用户拍板）：**镜像即产物**。云端构建前后端一体镜像推 ghcr.io，
> 香港服务器只 `docker compose pull && up -d`——零服务器构建、零本地大文件上传。
> 历史包袱（轮询 timer、巨型 CI、本地 deploy.sh）全部拆除。

## 1. 拓扑

```
本机（Windows / Git Bash）
  │  git push（几 KB 文本；正式发布用 tools/release.sh bump+tag）
  ▼
GitHub Actions（ci-cd.yml）
  ├─ ubuntu：构建前后端一体镜像 → ghcr.io/h2o-me/observatory:latest + :<sha>（gha 缓存，~2-4 分钟）
  ├─ agent/** 或 VERSION 变更时才动用 windows runner：构建 exe → 挂 Release latest-agent
  └─ deploy-hk：SSH 触发服务器 pull-and-restart.sh <sha> <agent_changed>
  ▼
香港服务器 /opt/observatory
  deploy/pull-and-restart.sh：
  ├─ （agent 更新时）从 Release 拉 zip → 容器内 package-add 登记
  ├─ 记录旧镜像 + DB 一行式在线快照
  ├─ compose pull（香港→ghcr 满速）→ compose up -d
  ├─ 容器内健康验证（容忍一次性 DB 迁移慢启动，最长 6 分钟）
  └─ 失败 → OBS_IMAGE_TAG=旧镜像 compose up -d（秒级回滚）
  ▼
在线受控端心跳拿到 update_offer → 自行升级
```

## 2. 日常操作

```bash
# 日常开发：push main 即自动上线（镜像 :sha，服务器自动拉取切换）
git push

# 正式发布（bump 版本 + tag，镜像额外打 vX.Y.Z 别名）：
tools/release.sh          # patch +1；minor/major/X.Y.Z 同理

# 本地测试（可选，CI 不跑测试）：
python -m pytest tests/unit tests/integration tests/contract tests/acceptance -m "not perf"
cd webui && pnpm typecheck && pnpm build
```

排障：

```bash
ssh obs   # 本机 ~/.ssh/config 里的别名（主机/端口/密钥只留在本机，不入库）
docker compose -f deploy/docker-compose.yml --env-file server/.env logs -f --tail 100
docker inspect --format '{{.Config.Image}}' observatory-api   # 当前镜像 ref
docker images ghcr.io/h2o-me/observatory                       # 本地镜像列表
# 手动回滚：
OBS_IMAGE_TAG=ghcr.io/h2o-me/observatory:<旧sha> docker compose -f deploy/docker-compose.yml --env-file server/.env up -d
```

## 3. 服务器一次性初始化（已完成，留档）

- `docker login ghcr.io -u H2O-ME`（令牌在 `/opt/observatory/.gh_read_token`，600）
- `setfacl -R -m u:10001:rX certs && setfacl -R -d -m u:10001:rX certs`（证书权限，续期后默认 ACL 自动生效，无需再 chown）
- `deploy/pull-and-restart.sh` 就位；GitHub secrets：`OBS_DEPLOY_KEY/HOST/PORT/USER`
- 旧机制全部移除：auto-update timer 三件套、deploy.sh、ci-gate、agent-dist 分支依赖

## 4. 设计要点（每条对应一次真实事故）

- **前后端一体镜像**：webui 在镜像内构建并直接由 FastAPI 托管（`BUNDLED_WEBUI` 优先），
  `/data/webui/.version` 数据卷发布机制已废除——"旧 SPA 配新 API"的登录死循环类别整体消失。
- **镜像不可变**：线上容器永远对应 ghcr 里一个确定 sha，回滚 = 指回旧 ref。
- **健康验证走容器内直连**：绕过反代/HostSplit 网络位形；首次启动可能跑 DB 迁移
  （v5 的 frame 复合索引在生产库上需要几分钟），验证窗口给足 6 分钟，迁移只发生一次。
- **stop_grace_period 保持 30s**：受控端 20s 长轮询在途连接需要优雅断连，缩短会 SIGKILL 真机连接。
- **构建在云端**：服务器的 CPU/内存上限（2g/4核）只影响运行时，与构建速度无关。

## 5. 凭据

| 凭据 | 位置 |
| --- | --- |
| GitHub PAT（repo+workflow+packages） | 本机 `.localdata/github-token`；服务器 `/opt/observatory/.gh_read_token`（600，只读用途，建议轮换成 read:packages 最小权限） |
| 服务器管理密钥 | `ssh obs`（本机 ~/.ssh/config 已配） |
| CI 部署密钥 | GitHub secret `OBS_DEPLOY_KEY`（deploy-hk 用） |
| git deploy key（只读） | 服务器 `~/.ssh/id_ed25519_observatory` |

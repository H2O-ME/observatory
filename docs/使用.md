# 使用（Observatory 0.3.7）

## 登录

打开 `https://control.tianhw.top`，输入管理员密码；开启二次验证后还需要 6 位动态码。
页脚显示的版本号来自服务端 `VERSION`，与安装脚本、受控端使用同一个号。

## 设备墙

首页是所有设备的卡片：

* 状态点：绿=在线（有活链路）、黄=受限（仅长轮询，实时控制不可用）、灰=离线；
* 卡片画面是最近一张截图，悬停显示采集时间；
* 顶部汇总在线/受限/离线数量；
* 右上角「实时连接」指示灯：熄灭表示控制台 WebSocket 断开，此时所有设备显示
  **状态未知**而不是沿用旧数据——这是刻意的（C5：时间只信服务端）。

## 设备详情

### 概览
资源占用、磁盘、登录会话、系统信息、重命名、远程操作、数据清理。
「远程操作」按钮是否可用由服务端 `presence.capabilities` 决定；不可用时写明原因
（例如「仅轮询通道，实时控制不可用」「设备未登录桌面，无法采集屏幕」）。

### 实时
点「开始实时控制」建立一次授权会话（默认 5 分钟，可在 30s–3600s 范围调整）。之后：

* 鼠标移动/左右中键/滚轮直接作用到受控端；
* 键盘：画面获得焦点后直接输入；输入法/粘贴场景用下方输入框；
* 结束会话或 TTL 到期后，输入立即停止转发（0.3.0 修复：撤销不只关画面）。

实时控制只在 WebSocket 载体下可用；设备「受限」时该栏明确说明，并提示仍可截图/文件/命令。

### 时间线
选日期与时间段；服务端按桶聚合，每格显示代表画面与帧数；点格全屏，左右箭头逐张翻阅。
画面 URL 不可变，浏览器会缓存；时间以服务端 `server_time_ms` 校准，不用本机时钟判断新鲜度。

### 文件
空路径显示驱动器列表；单击选中，双击进目录；底部操作条下载/重命名/删除；
右上角新建文件夹、上传（任意大小，按 1 MiB 分片）。删除目录会连带内容（二次确认），
所有写操作进审计。超时预算由服务端 `deadline_ms` 决定，前端不再固定 20s。

### 命令
历史命令与结果，可展开完整 JSON；失败会显示受控端返回的错误原文（`{code,message,retryable}`）。

## 设置

* **服务器**：版本、运行时长、通道数、存储占用。
* **安装程序**：生成**一次性安装令牌**（默认 24 小时、单次使用、绑定首台设备，
  有效期可在设置里调），
  下载 `.cmd`/`.ps1`。文件里带令牌、版本号与多个服务器地址；目标机双击运行即可，
  不需要手输参数。安装只弹一次 UAC，之后升级/远程卸载/远程控制都不弹。
* **令牌管理**：查看已生成令牌的状态（未使用/已使用/已过期），删除即撤销。
  0.3.1 起服务器只接受一次性安装令牌，旧的共享注册码机制已移除。
* **分组参数**：采集、连接、实时控制、文件、自动更新、保留、归档。
* **修改密码**、**二次验证**（关闭必须输入验证码）。

采集类参数可按设备覆盖（设备概览页修改后只影响那一台）。

## 更新

* 上传 `observatory-agent-<版本>.zip`（文件名必须带版本号，sha256 由服务端计算）；
* 「待升级设备」列出仍是旧版本的机器；
* 受控端在心跳里拿到更新后自行下载、校验 sha256、预检、原子替换、失败回滚并重启，
  **不需要重新安装、不弹 UAC**；
* 服务端升级：`git push` 即自动上线（CI 构建镜像，服务器拉取切换）；正式发布用 `tools/release.sh`，见 docs/发布与更新链路.md。

## 审计

按动作过滤，例如 `device.uninstall`、`control.grant`、`files.op`、`settings.update`、
`install.token_create`、`install.token_delete`。记录操作者、IP、设备与时间。默认保留 180 天。

## 系统

服务器自身的运行视图：版本、运行时长、各载体（WS/轮询）会话数、待处理命令、
存储占用与磁盘剩余、保留策略现值。数据全部来自 `/api/v1/system` 与 `/api/v1/health`，
控制台不做本地计算。

## 账号与安全

修改控制台密码、启用/关闭 TOTP 两步验证。密码规则与 TOTP 校验都在服务端，
控制台只做即时反馈。右上角人形图标进入。

## 数据保留

默认画面保留 **14 天**、审计 **180 天**、命令 **30 天**，可在设置里改；
超出按天清理，可配合存储配额使用。清空历史画面会立刻删除该设备画面文件与数据库记录。

## 手机与手表

* 宽度 ≤ 860px：底部导航（设备/备份/更新/审计/系统/设置），单列或双列卡片；
* 宽度 ≤ 380px（含手表）：极简布局，只显示状态、名称、最近画面；点开设备用标签页切换；
* 触控目标 ≥ 44px，输入框 16px（避免 iOS 聚焦缩放）；
* 手表/低性能设备自动关闭毛玻璃与背景光晕。

## 常见疑问

**为什么设备显示「受限」却还能截图？**
「受限」指没有活 WebSocket 链路、实时控制不可用；截图/文件走同一链路的 HTTP 长轮询载体，仍可用。

**为什么时间线上有空格子？**
该时段没有采集到画面（设备休眠、关机，或变化检测判定画面未变化）。

**远程卸载后设备会怎样？**
服务停止、删除自身文件与服务注册、清理防火墙规则与计划任务，然后调用接口确认。
服务器标记「已卸载」。全程 SYSTEM 运行，不弹 UAC；卸载 helper 失败时会保持在线并上报
`uninstall_failed`（0.3.0 修复）。

**安装令牌过期/泄露了怎么办？**
在控制台删除该令牌；已消费的令牌不能再用于其它机器。泄露时只需删除令牌本身，不需要更换服务器密钥。

**卸载后还能恢复吗？**
需要重新运行安装程序并生成新令牌；设备身份（uid）在重装后保持不变。

**为什么删除按钮是灰的？**
设备仍在线。先远程卸载，等状态变成「已卸载」再删除记录，避免留下仍在尝试上报的机器。

**为什么接口返回 `AUTH`/`GONE`？**
0.3.0 统一错误体 `{code,message,retryable}`：`AUTH`=令牌/权限，`GONE`=设备已卸载或不存在，
`TIMEOUT`=超过 deadline，`RATE`=限流；`retryable` 指示是否值得重试。

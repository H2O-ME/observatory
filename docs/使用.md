# 使用

## 登录

打开 `https://control.tianhw.top`，输入管理员密码。开启二次验证后还需要 6 位动态码。

页脚显示的版本号与服务器、受控端安装包一致（都来自 `VERSION`）。

## 设备墙

首页是所有设备的卡片：

* 状态点：绿=在线（WebSocket），黄=受限（仅轮询），灰=离线
* 卡片上的画面是最近一张截图，鼠标悬停显示采集时间
* 顶部汇总"在线 / 受限 / 离线"数量
* 右上角"实时连接"指示灯：**熄灭表示控制台的 WebSocket 断了**，此时所有状态会标成"状态未知"，
  而不是继续显示旧数据——这是刻意的

点卡片进入设备详情。

## 设备详情

### 概览
资源占用（CPU/内存）、磁盘、登录会话、系统信息、重命名、远程操作、数据清理。

"远程操作"里的按钮是否可用，取决于服务端给出的 `presence.capabilities`。按钮变灰时会写明原因。

### 实时
点击「开始实时控制」建立一次授权会话（默认 10 分钟，可在设置里改）。之后：

* 鼠标移动/左中右键/滚轮直接作用在受控端
* 键盘：在画面获得焦点后直接打字；用于输入法/粘贴的场景用下方输入框
* 「全屏」在手机横屏或手表上更好用

**实时控制只在 WebSocket 通道下可用。** 设备显示"受限"时这一栏会明确说明，并提示仍然可以截图/文件/命令。

### 时间线
* 选日期（左右箭头 / 今天）和时间段
* 服务端按桶聚合，每格显示该时段的代表画面与帧数
* 点任意一格全屏查看，左右箭头逐张翻阅
* 画面 URL 不可变，浏览器会缓存——第二次看同一张不会重新下载

### 文件
* 空路径显示驱动器列表；点进去即列目录
* 单击选中，双击进目录
* 底部操作条：下载 / 重命名 / 删除
* 右上：新建文件夹、上传（任意大小，按 1 MiB 分片）
* 搜索：在当前目录递归匹配名称

删除目录会连带内容（有二次确认）。所有写操作都进审计。

### 命令
历史命令与结果，可展开看完整 JSON。失败会显示受控端返回的错误原文。

## 设置

* **服务器**：版本、运行时长、通道数、存储占用
* **安装程序**：直接点「下载安装程序 (.cmd)」，拷到目标机器**双击运行**即可。
  文件里已经写好注册码、版本号和两个服务器地址；不用输参数、不用改命令。
  安装过程只弹一次 UAC，之后升级、远程卸载、远程控制都不会再弹
* **分组参数**：采集、连接、实时控制、文件、自动更新、保留、归档
* **修改密码**、**二次验证**（关闭必须输入验证码）

采集类参数可以按设备覆盖：在设备详情的概览页修改后只影响那一台。

## 更新

* 上传 `observatory-agent-<版本>.zip`（文件名必须带版本号）
* "待升级设备"列出仍是旧版本的机器
* 受控端在心跳里拿到新版本后自行下载、校验、替换、重启——**不需要重新安装，不弹 UAC**

## 审计

按动作过滤，例如 `device.uninstall`、`control.grant`、`files.op`、`settings.update`。
记录操作者、IP、设备与时间。

## 手机与手表

* 宽度 ≤ 860px：底部导航（设备/更新/审计/设置），单列或双列卡片
* 宽度 ≤ 380px（含手表）：极简布局，只显示状态、名称、最近画面；点开设备后用标签页切换
* 触控目标 ≥ 44px，输入框 16px（避免 iOS 聚焦缩放）
* 手表/低性能设备自动关闭毛玻璃与背景光晕，减少重绘

## 常见疑问

**为什么设备显示"受限"却还能截图？**
"受限"指实时控制通道不可用（没有 WebSocket），不是设备离线。截图和文件走命令总线，轮询也能到。

**为什么时间线上有空格子？**
该时段没有采集到画面（受控端休眠、关机、或变化检测判定画面未变化）。

**远程卸载后设备会怎样？**
受控端服务停止、删除自身文件与服务注册、清理防火墙规则与计划任务，然后调用接口确认。
服务器把状态标为"已卸载"。整个过程以 SYSTEM 运行，**不会弹 UAC**。

**卸载后还能恢复吗？**
不能，需要重新运行安装程序（控制台设置页重新下载即可）。安装包与注册码仍然有效，重新安装后设备身份（uid）不变。

**为什么删除按钮是灰的？**
设备还在线。先远程卸载，等状态变成"已卸载"再删除记录，避免留下仍在尝试上报的机器。

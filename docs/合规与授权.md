# 合规与授权（Observatory 0.3.7）

## 一句话

这个系统能远程看到并操作 Windows 桌面。**只允许部署在你拥有、或已获得设备所有者明确书面授权的机器上。**

## 部署前必须确认

1. 目标设备属于你本人、你的组织，或所有者已在知情前提下书面同意；
2. 已向使用者告知：设备上存在会定时截屏、可远程操作的软件；
3. 符合所在地区法律（劳动合同、隐私保护、数据安全相关法规）；
4. 采集范围与业务目的相匹配：不要采集与目的无关的屏幕内容。

明确禁止：未经同意监控他人设备、窃取账号密码、规避他人安全措施、在他人不知情的情况下安装或隐藏运行。

## 技术上如何把边界做实（0.3.0）

| 机制 | 作用 |
| --- | --- |
| 安装无凭据 | 安装脚本不含任何令牌；设备身份由 Windows MachineGuid 派生，重装保持同一 uid。首次上线自动注册并下发设备令牌，之后每个请求都必须带它（标识符 ≠ 凭证）；删除设备只忘记记录，不封禁 |
| 安装可见 | 服务名 `ObservatoryAgent`、目录 `C:\Program Files\Observatory` 均为明文，不隐藏、不伪装 |
| 状态可见 | 控制台始终显示真实状态（在线/受限/离线/已卸载/状态未知），并给出原因，不伪装成正常 |
| 二次验证 | 控制台可启用 TOTP；关闭时必须校验当前验证码 |
| 实时控制授权 | 每次实时控制是独立、有 TTL 的授权会话；撤销后输入立即停止转发，且写审计 |
| 审计日志 | 登录、设置变更、命令下发、文件写操作、实时控制、卸载、安装令牌创建/撤销全部留痕 |
| 保留期限 | 画面默认 14 天、审计默认 180 天、命令默认 30 天，可按天清理并配置存储配额 |
| 远程卸载 | 不需要目标机用户配合、不需要 UAC——为了在无人值守机器上能彻底移除，而不是为了不可移除；失败会保持在线并上报 `uninstall_failed` |
| 网络边界 | 8443 默认只绑回环、由 nginx 反代；`OBS_TRUST_FORWARDED_FOR` 默认 false；容器非 root + 只读根文件系统 |

## 数据处理

* 画面存在服务器 `/data/frames`，按 `设备/日期/小时` 分目录；缩略图另存；
* 数据库只存相对路径与元数据（大小、尺寸、时间、会话）；
* 可选的 GitHub 归档是**私有仓库**，默认关闭；关闭时不产生任何外部网络请求；
* 不采集键盘记录、不采集剪贴板、不采集音频，不持久化输入法内容（实时控制只转发即时事件）；
* 备份（含画面与证书私钥）按敏感数据管理：`umask 077`、目录 700，建议加密后异地保存。

## 保留与删除

* 默认画面保留 **14 天**、审计 **180 天**、命令 **30 天**，可在设置里改；
* 「清空历史画面」立刻删除该设备的全部画面文件与数据库记录；
* 「删除设备记录」会同时删除该设备在归档仓库中的文件；设备必须已离线或已卸载；
* 卸载受控端后，服务器侧数据仍需手动删除（有意保留卸载证据与审计链）；
* 安装令牌到期或被使用后不可复用；撤销（删除）立即生效。

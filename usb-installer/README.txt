Observatory 受控端 —— 离线/现场安装包
=====================================

用途
----
在没有控制台环境、或需要现场安装时使用。安装后受控端会自行连接服务器，
并在服务器推出新版本时自动更新，不需要再来一次现场安装。

0.3.0 凭据模型（重要）
----------------------
* 推荐使用「一次性安装令牌」：
    - 控制台「设置 → 安装程序 → 生成安装令牌」；
    - 默认 TTL 24 小时（控制台设置 install_token_ttl_minutes，可调到 30–60 分钟），单次使用；
    - 首次注册时绑定该设备，之后令牌立即失效；
    - 丢失/泄露时在控制台删除令牌即可撤销，不需要轮换整串共享注册码。
* 旧版共享注册码（OBS_ENROLL_CODE）仅用于 0.2.x 受控端兼容；0.3.0 新机不要再用。
* 本目录的脚本不内置任何凭据（U 盘丢失不等于令牌泄露）——令牌由现场人员输入。

步骤（推荐：用控制台下载的安装程序）
----
1. 在控制台「设置 → 安装程序」生成一次性安装令牌，并下载安装程序 (.cmd)。
2. 把它拷到 U 盘或目标机器，双击运行。
3. 文件里已经带好令牌、版本号，以及多个服务器地址（逐个尝试，任意一个可达即可安装）。
4. 安装过程中会弹一次 UAC —— 这是整个生命周期里唯一的一次。
   之后的自动更新、远程卸载、远程控制都由 SYSTEM 服务完成，不再弹窗。

步骤（本目录的通用引导程序）
----
1. 双击 Install-ObservatoryAgent.cmd。
2. 按提示输入服务器地址（默认 control.tianhw.top）和一次性安装令牌
   （旧服务器可改用共享注册码）。
3. 它会去服务器下载上面那个完整安装脚本并执行，后续与上面相同。

撤销与失效
----------
* 令牌：控制台「设置 → 安装程序」列表内删除/撤销；已过期或被使用的令牌不可复用。
* 共享注册码：把 server/.env 的 OBS_ENROLL_CODE 置空并重启服务端（影响所有旧受控端）。
* 如果令牌已在某台机器上被消费，该机器仍可正常使用；重装需要新令牌。

安全说明
--------
* 本目录不包含任何硬编码的注册码或长期令牌。
* 控制台域名与受控端接入域名是分开的：
    - control.tianhw.top        控制台 + 受控端（两者都提供）
    - observatory.123423.xyz    仅受控端接入，不提供控制台
  两个域名的受控端接口互为备份，任意一个可达即可完成安装与上报。
* 安装脚本从服务器实时渲染，其中显示的版本号与服务器、控制台完全一致。

故障排查
--------
* 安装日志：%TEMP%\observatory-install.log
* 服务名：ObservatoryAgent
* 诊断命令（安装目录内）：
    observatory-agent.exe --doctor
    observatory-agent.exe --status
* 手动卸载（需要管理员）：
    observatory-agent.exe --uninstall
  注意：远程卸载不需要管理员，也不会弹 UAC。
* 安装报 403/401：令牌已过期、已被使用或不属于该服务器；重新生成令牌。

授权使用
--------
本软件用于经授权的设备管理。部署到他人设备前，请确保已取得书面授权，
并在《合规与授权》文档要求范围内使用。详见仓库 docs/合规与授权.md。

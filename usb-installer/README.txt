Observatory 受控端 —— 离线/现场安装包
=====================================

用途
----
在没有控制台环境、或需要现场安装时使用。安装后受控端会自行连接服务器，
并在服务器推出新版本时自动更新，不需要再来一次现场安装。

步骤
----
1. 在控制台「设置」页复制注册码。
2. 双击 Install-ObservatoryAgent.cmd。
3. 按提示输入服务器地址（默认 control.tianhw.top）和注册码。
4. 安装过程中会弹一次 UAC —— 这是整个生命周期里唯一的一次。
   之后的自动更新、远程卸载、远程控制都由 SYSTEM 服务完成，不再弹窗。

安全说明
--------
* 本目录不包含任何硬编码的注册码或长期令牌。
* 控制台域名与受控端接入域名是分开的：
    - control.tianhw.top        控制台 + 受控端（两者都提供）
    - observatory.123423.xyz    仅受控端接入，不提供控制台
  两个域名的受控端接口互为备份，任意一个可达即可完成安装与上报。
* 安装脚本从服务器实时渲染，其中显示的版本号与服务器、控制台完全一致。

故障排查
--------
* 安装日志：%TEMP%\observatory-install.log
* 服务名：ObservatoryAgent
* 诊断命令（安装目录内）：
    observatory-agent.exe --doctor
    observatory-agent.exe --status
* 手动卸载（需要管理员）：
    observatory-agent.exe --uninstall
  注意：远程卸载不需要管理员，也不会弹 UAC。

授权使用
--------
本软件用于经授权的设备管理。部署到他人设备前，请确保已取得书面授权，
并在《合规与授权》文档要求范围内使用。详见仓库 docs/合规与授权.md。
